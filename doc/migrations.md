| Action                   | Command                       |
| ------------------------ | ----------------------------- |
| Create database          | `dbmate create`               |
| Drop database            | `dbmate drop`                 |
| Create migration         | `dbmate new <migration_name>` |
| Run migrations           | `dbmate up`                   |
| Roll back last migration | `dbmate down`                 |
| Show migration status    | `dbmate status`               |
| Dump schema              | `dbmate dump`                 |
