# Отметки
## Требования
* Авторизованный пользователь может создавать отметки выполнения своих привычек.
* Повторная отправка отметки для той же привычки и даты обновляет значение без создания дубликата.
* Пользователь может получать свои отметки за указанный период.
* Начальная дата периода включается, конечная не включается.
* Пользователь не может создавать отметки для чужих привычек.
* Идентификаторы `BIGINT` в ответах представлены строками, дата возвращается как ISO-строка.

## Сценарии
### 1. Создание и получение отметки
Пользователь с действительной сессией создаёт отметку для своей привычки:

```http
POST /metrics
Content-Type: application/json
Cookie: jwt=<условный-JWT>

{
  "habit_id": "42",
  "date": "2026-06-15",
  "value": true
}
```

Сервер возвращает `201 Created`:

```json
{}
```

Пользователь запрашивает отметки за период:

```http
GET /metrics?start=2026-06-15&end=2026-06-16
Cookie: jwt=<условный-JWT>
```

Сервер возвращает `200 OK`:

```json
[
  {
    "id": "1",
    "user_id": "42",
    "habit_id": "42",
    "date": "2026-06-15T00:00:00.000Z",
    "value": true
  }
]
```

### 2. Снятие отметки
Пользователь с действительной сессией повторно отправляет отметку для той же привычки и даты:

```http
POST /metrics
Content-Type: application/json
Cookie: jwt=<условный-JWT>

{
  "habit_id": "42",
  "date": "2026-06-15",
  "value": false
}
```

Сервер обновляет отметку и возвращает `201 Created`:

```json
{}
```

Пользователь запрашивает отметки за тот же период:

```http
GET /metrics?start=2026-06-15&end=2026-06-16
Cookie: jwt=<условный-JWT>
```

Сервер возвращает `200 OK` с одной обновлённой отметкой:

```json
[
  {
    "id": "1",
    "user_id": "42",
    "habit_id": "42",
    "date": "2026-06-15T00:00:00.000Z",
    "value": false
  }
]
```

### 3. Запрет создания отметки для чужой привычки
Пользователь с действительной сессией отправляет запрос с идентификатором чужой привычки:

```http
POST /metrics
Content-Type: application/json
Cookie: jwt=<условный-JWT>

{
  "habit_id": "43",
  "date": "2026-06-15",
  "value": true
}
```

Сервер не создаёт отметку и возвращает `404 Not Found`:

```json
{
  "error": "Habit not found"
}
```

Значение JWT в примерах условно и создаётся сервером.
